BIBDESK RAG MANUAL

BibDesk RAG searches a local BibDesk library and its linked attachments. It reads
the bibliography and attachments without changing them, and keeps the derived
SQLite index in user-owned application data outside Python and Homebrew.

USAGE
  bibdesk-rag [INFORMATION OPTION]
  bibdesk-rag [--temp PATH] OPERATION [OPTIONS]

With no arguments, show a brief help overview and exit. Use -h/--help for the
complete option reference. Choose one operation per invocation.
Unrelated options and conflicting operations are errors, before any operation
runs. Quote paths or queries containing spaces.

INFORMATION (no configuration or index required)
  -h, --help
      Show the complete option reference and exit.
  -v, --version
      Show the version and software citation and exit.
  -e, --example
      Show common usage examples and exit.
  -r, --readme
      View this bundled manual. Use a local pager on a terminal; otherwise print
      to standard output. No browser or network access is needed.
  -o, --output {manual,config-template,citation}
      Print the selected resource to standard output. File redirection is up to
      the caller. citation is BibDesk RAG's BibTeX @manual entry, authored by
      Kento Yanagisawa, not a library paper.

OPERATIONS
  --setup
      Start interactive setup. Both standard input and standard error must be
      terminals. Register a library, optionally build/update its index and
      optionally register its local MCP server with Codex. Existing conflicting
      Codex registrations are not replaced. Setup reports local MCP handshake
      separately from actual searches through Codex.

  -c, --config ACTION [PATH]
      show          Show the selected configuration, resolved paths and every
                    extraction option, including omitted values' defaults.
      path          Show the selected configuration file's absolute path.
      use PATH      Validate and remember an existing configuration.
      create [PATH] Create a new configuration and remember it. Requires --bib.
                    If PATH is omitted, use BIBDESK_RAG_CONFIG if set, otherwise
                    the configuration directory's config.toml. A saved custom
                    selection does not change this creation destination.
                    Never overwrite an existing configuration.

      show/path do not open the bibliography or index and do not change files.
      use/create preserve existing indexes and source files.

  -i, --index ACTION
      update        Create an index if absent, otherwise update incrementally.
      rebuild       Re-extract all configured sources and rebuild derived data.
      status        Show indexed counts, extraction states and update metadata.
      check         Check SQLite, foreign-key and FTS consistency and attachment
                    errors. This is read-only and may require substantial memory.

  -p, --paper ACTION VALUE
      search QUERY       Search bibliography metadata and/or indexed text.
      show KEY           Retrieve the indexed bibliography record for a citekey.
      attachments KEY    List the paper's indexed attachments and extraction state.
      context QUERY      Retrieve a bounded bundle of excerpts and exact citations.

CONFIGURATION
  --temp PATH
      Use this configuration for one invocation without changing the saved
      selection. Cannot be combined with --config use or --config create.
      With --setup, generated configuration/index files and any approved Codex
      registration are retained, but the saved configuration selection is not
      changed. Repeat the same --temp PATH --setup command to resume.
  --bib FILE
      BibDesk library to register; required for --config create only.
  --data-dir DIR
      Index directory for --config create only.

New-install defaults on macOS and other platforms:
  Configuration: ~/.config/bibdesk-rag/config.toml
  Index:         ~/.local/share/bibdesk-rag/index.sqlite3

Selection priority is --temp PATH, BIBDESK_RAG_CONFIG, the saved selection in
active-config.json, then the default configuration. Missing saved selections
fail instead of silently selecting another library. Repair with --config use.
The former macOS Application Support directory is not auto-detected.

The configuration directory is BIBDESK_RAG_HOME, else XDG_CONFIG_HOME/bibdesk-rag,
else ~/.config/bibdesk-rag. New index placement uses --data-dir, BIBDESK_RAG_HOME,
then XDG_DATA_HOME/bibdesk-rag. Without those, default configurations use
~/.local/share/bibdesk-rag; custom configurations use their parent directory.
Existing configurations' database values are retained. Relative TOML paths are
relative to that configuration file. Use a separate database for each library.

Normal MCP registrations omit arguments and follow the CLI's selected configuration.
Only --temp PATH --setup pins a temporary configuration during registration.
Changing the CLI's saved selection does not rewrite existing Codex registrations
which pin an explicit configuration path. MCP is retrieval-only and opens SQLite
read-only; index maintenance is done through the CLI.

OUTPUT
  --format {text,json,bibtex}
      text is the default, including when output is piped or redirected.
      json is available for configuration, index and paper results.
      bibtex is only valid with --paper show.
  --verbose
      Print full parser warnings and attachment issues during update/rebuild.
  --no-progress
      Hide the update/rebuild terminal progress bar.

Results go to standard output; progress and diagnostics go to standard error.
Progress requires both output streams to be terminals and TERM not to be dumb.
JSON output disables progress. Verbose diagnostics do not contaminate JSON.
Information/setup operations do not accept --format; unrelated options fail.

SEARCH AND EVIDENCE
  --scope {all,metadata,fulltext}  Search scope; default all (search only).
  --top N                       Result count, 1..100; search default 10,
                                context default 5.
  --per-paper N                 Excerpts per paper, 1..10; default 2.
  --citekey KEY                 Restrict selected-paper text retrieval; repeatable.
  --metadata-query QUERY        Select candidates before all-scope search/context;
                                cannot be combined with --citekey.
  --doi DOI                     Exact DOI filter for metadata search.
  --author NAME                 Author filter for metadata search.
  --year YEAR                   Year filter for metadata search.
  --max-chars N                 Context text budget, 256..100000; default 10000.

Default all-scope search selects up to 100 metadata candidates and searches their
indexed text. If no metadata candidates match, it falls back to indexed text.
DOI/citekey exact lookup is independent of BM25. Keyword mode uses no embeddings. OCR is not performed. Metadata matches do not by themselves establish full-text evidence.

Citations identify citekey, DOI when present, attachment path, chunk ID and PDF
page range, sheet/row or ZIP member location. PDF pages start at 1 from the file's
first page. Verify scientific claims against original sources. No results do not
prove that relevant literature is absent. Context reports uncertainty/truncation.

INDEX UPDATES
  --verify-hashes
      Hash attachments even when size and modification time are unchanged.
      Valid with update/rebuild only.

Incremental updates reuse unchanged extraction results. Changed extraction
settings trigger re-extraction. Writes are transactional; a fatal failure retains
the previous committed index. Missing/unreadable attachments are recorded as
errors while other files continue. Update after BibDesk changes or source moves.

Supported text inputs: PDF, CSV/TSV, XLSX and safe ZIP members. Spreadsheet formulas
are never executed. Archive traversal, symlinks, encryption and excessive sizes
are rejected. No automatic network requests, downloads or OCR occur. Semantic inference is opt-in.
Configuration, index and SQLite sidecars must not overlap source files.

EXAMPLES
  bibdesk-rag --setup
  bibdesk-rag --config create --bib "/path/to/library.bib"
  bibdesk-rag --config show --format json
  bibdesk-rag --index update
  bibdesk-rag --index update --verify-hashes
  bibdesk-rag --index status
  bibdesk-rag --paper search "RecQ helicase" --top 5
  bibdesk-rag --paper show Example2025 --format bibtex
  bibdesk-rag --temp "/path/to/other.toml" --index update
  bibdesk-rag --output config-template > example.toml

MIGRATION
  setup             -> --setup
  init              -> --config create
  config show/path  -> --config show/path
  config use PATH   -> --config use PATH
  index             -> --index rebuild
  update            -> --index update
  status / doctor   -> --index status / --index check
  search / context  -> --paper search / --paper context
  get KEY           -> --paper show KEY
  attachments KEY   -> --paper attachments KEY
  --json            -> --format json

Old CLI subcommands are rejected with migration guidance. The MCP executable
retains a hidden --config PATH compatibility alias for existing registrations;
normal new registrations omit arguments and follow the selected configuration.
Use --temp PATH only to pin a configuration. MCP tool names/schemas are unchanged.

日本語マニュアル / JAPANESE MANUAL

BibDesk RAGはローカルBibDeskライブラリとリンク添付を検索します。書誌・添付を
変更せずに読み、派生SQLite索引はPython・Homebrew外の利用者アプリデータに置きます。

使い方 / USAGE
  bibdesk-rag [案内オプション]
  bibdesk-rag [--temp PATH] 操作 [オプション]

引数なしでは短縮ヘルプを表示して終了します。全オプションは -h/--help です。
主操作は1回につき1つ。無関係なオプションや競合操作は処理前にエラーにします。
空白を含むパス・検索語は引用符で囲みます。

案内（設定・索引は不要） / INFORMATION
  -h, --help
      全オプションを表示して終了します。
  -v, --version
      版番号とソフトウェア引用情報を表示して終了します。
  -e, --example
      よく使う操作例を表示して終了します。
  -r, --readme
      この同梱マニュアルを表示します。端末ではローカルページャーを使い、
      それ以外は標準出力へ出します。ブラウザー・ネットワーク接続は不要です。
  -o, --output {manual,config-template,citation}
      資料を標準出力へ出します。ファイルへのリダイレクトは呼出し側で指定します。
      citationはKento Yanagisawa著のBibDesk RAG自身のBibTeX @manualで、
      ライブラリの文献ではありません。

操作 / OPERATIONS
  --setup
      対話型セットアップ。標準入力・標準エラーが両方とも端末である必要があります。
      ライブラリ登録、任意の索引作成・更新、任意のCodexローカルMCP登録を行います。
      競合するCodex登録は置き換えず、ローカルMCP疎通とCodex実検索を分けて示します。

  -c, --config ACTION [PATH]
      show          選択中の設定・解決済みパス・全抽出値を表示（省略値の既定も含む）。
      path          選択中の設定ファイルの絶対パスを表示。
      use PATH      既存設定を検証して選択を保存。
      create [PATH] 新規設定を作成して選択を保存。--bib が必要です。
                    PATH省略時は BIBDESK_RAG_CONFIG、なければ設定用ディレクトリの
                    config.toml を使います。保存済みカスタム選択は作成先に影響しません。
                    既存設定は上書きしません。

      show/path は書誌・索引を開かずファイルも変更しません。
      use/create は既存索引・原本を保持します。

  -i, --index ACTION
      update        索引がなければ作成し、あれば差分更新。
      rebuild       設定した全原本を再抽出し、派生データを再構築。
      status        索引件数・抽出状態・更新情報を表示。
      check         SQLite・外部キー・FTS整合性と添付エラーを検査。
                    読み取り専用ですが、多くのメモリが必要な場合があります。

  -p, --paper ACTION VALUE
      search QUERY       書誌情報・索引本文を検索。
      show KEY           citekeyの索引書誌レコードを取得。
      attachments KEY    索引添付と抽出状態を一覧表示。
      context QUERY      文字数を制限した抜粋と正確な引用を取得。

設定 / CONFIGURATION
  --temp PATH
      今回だけ別の設定を使い、保存済み選択を変更しません。
      --config use/create とは併用できません。--setup で作成した設定・索引や
      承認したCodex登録は保持されますが、設定選択は保存しません。
      再開には同じ --temp PATH --setup を使います。
  --bib FILE
      登録するBibDeskライブラリ。--config create 専用の必須引数です。
  --data-dir DIR
      --config create 専用の索引ディレクトリ。

macOSを含む新規導入の既定保存先：
  設定: ~/.config/bibdesk-rag/config.toml
  索引: ~/.local/share/bibdesk-rag/index.sqlite3

設定の優先順は --temp PATH、BIBDESK_RAG_CONFIG、active-config.json の保存済み選択、
既定設定です。保存済み設定がなければ別ライブラリへ切り替えずエラーにします。
--config use で選び直します。旧macOS Application Supportは自動検出しません。

設定用ディレクトリは BIBDESK_RAG_HOME、XDG_CONFIG_HOME/bibdesk-rag、
~/.config/bibdesk-rag の順です。新規索引は --data-dir、BIBDESK_RAG_HOME、
XDG_DATA_HOME/bibdesk-rag の順です。どれもなければ、既定設定には
~/.local/share/bibdesk-rag、カスタム設定にはその親ディレクトリを使います。
既存設定の database は保持します。TOMLの相対パスはその設定ファイルが基準です。
ライブラリごとに別のDBを使います。

通常のMCP登録は引数なしでCLIの設定選択に追従します。--temp PATH --setup の場合だけ
一時設定を固定して登録します。CLIの選択を変えても、設定パスを固定したCodex登録は書き換えません。
MCPは検索・参照だけでSQLiteを読み取り専用で開き、索引保守はCLIで行います。

出力 / OUTPUT
  --format {text,json,bibtex}
      textが既定で、パイプ・リダイレクトでも同じです。
      jsonは設定・索引・文献の結果に使えます。
      bibtexは --paper show 専用です。
  --verbose
      update/rebuild時の全パーサー警告・添付問題を表示。
  --no-progress
      update/rebuildの端末進捗バーを無効化。

結果は標準出力、進捗・診断は標準エラーです。進捗は両出力が端末で、
TERMがdumbでない場合に表示します。JSONでは進捗を無効にし、詳細診断も混ぜません。
案内・setupには --format を使えず、無関係なオプションは拒否します。

検索と証拠 / SEARCH AND EVIDENCE
  --scope {all,metadata,fulltext}  検索範囲。search専用、既定all。
  --top N                       結果数1..100。search既定10、context既定5。
  --per-paper N                 文献ごとの抜粋1..10、既定2。
  --citekey KEY                 本文取得を選択文献に限定。複数指定可。
  --metadata-query QUERY        all検索・contextの書誌候補を指定。
                                --citekey とは併用不可。
  --doi DOI                     metadata検索のDOI完全一致。
  --author NAME                 metadata検索の著者フィルター。
  --year YEAR                   metadata検索の年フィルター。
  --max-chars N                 contextの文字数256..100000、既定10000。

既定all検索は最大100件の書誌候補を選んで索引本文を検索し、書誌候補がなければ
索引本文全体へフォールバックします。DOI/citekey完全一致はBM25と独立しています。
既定のキーワード検索は埋め込みを使いません。OCRは行わず、書誌一致だけを本文の証拠とは扱いません。

引用はcitekey、記録がある場合のDOI、添付パス、chunk ID、PDFページ範囲または
シート・行・ZIPメンバーを示します。PDFはファイル先頭を1ページとします。
科学的な主張は原本と照合してください。結果0件は関連文献の不在を証明しません。
contextは未検証・省略を報告します。

索引更新 / INDEX UPDATES
  --verify-hashes
      サイズ・更新日時が同じ添付もハッシュ検査します。update/rebuild専用です。

差分更新は未変更の抽出結果を再利用し、抽出設定の変更は再抽出します。
書き込みはトランザクションで、致命的失敗では前回コミットした索引を保持します。
欠損・読めない添付はエラーとして記録し、他ファイルを続行します。
BibDeskの変更・原本移動後には索引を更新してください。

対応本文はPDF、CSV/TSV、XLSX、安全なZIPメンバーです。数式は実行せず、
アーカイブのパス逸脱・symlink・暗号化・過大サイズを拒否します。
自動ネットワーク通信・ダウンロード・OCRは行いません。意味検索は任意です。
設定・索引・SQLite補助ファイルは原本と重ねてはいけません。

  bibdesk-rag --setup
  bibdesk-rag --config create --bib "/path/to/library.bib"
  bibdesk-rag --config show --format json
  bibdesk-rag --index update
  bibdesk-rag --index update --verify-hashes
  bibdesk-rag --index status
  bibdesk-rag --paper search "RecQ helicase" --top 5
  bibdesk-rag --paper show Example2025 --format bibtex
  bibdesk-rag --temp "/path/to/other.toml" --index update
  bibdesk-rag --output config-template > example.toml

移行 / MIGRATION
  setup             -> --setup
  init              -> --config create
  config show/path  -> --config show/path
  config use PATH   -> --config use PATH
  index             -> --index rebuild
  update            -> --index update
  status / doctor   -> --index status / --index check
  search / context  -> --paper search / --paper context

旧CLI構文は移行先を案内して拒否します。MCP実行ファイルは既存登録用に非表示の
--config PATH 互換引数を保持します。通常の新規登録は引数なしで選択中の設定に追従し、
設定を固定する場合だけ --temp PATH を使います。
MCPツール名・スキーマは変わりません。

SEMANTIC SEARCH / 意味検索（任意）
  --setup: choose semantic search; a new config defaults to no.
  A missing model is downloaded only after an explicit second choice.
  Selecting no never loads inference dependencies or downloads a model.
  Existing configs retain the current choice as the default.
  Setup changes only the selected semantic.enabled option, preserving other TOML/comments.

  Development: use .python-version Python 3.12.13 and the existing .venv.
    .venv/bin/python -m pip install -e '.[dev,semantic]'
  Pip: install the semantic extra in your existing standard venv if needed.
  Homebrew Apple Silicon: locked inference wheels are included in the Formula environment.
  No additional venv or runtime pip installation is needed. Model weights are separate.

  --index update      Update bibliography/text and enabled title/abstract vectors
  --index rebuild     Rebuild derived text and enabled vectors
  --index status      Show metadata/text/vector coverage, stale count, model and timestamps
  --index check       Read-only SQLite/FTS/vector integrity checks; no model required
  --semantic download Explicit noninteractive model download (requires enabled=true)
  --paper search QUERY --mode semantic [--top N]
  --paper search QUERY --mode keyword    Existing default behavior

  Semantic limit defaults to semantic.default_limit (5); range 1..100.
  Query limit: 2,000 characters and the configured model token limit.
  Keyword scopes/filters do not apply to semantic mode.
  MCP: semantic_search_papers(query, limit=5); existing tools remain compatible.
  The same index.sqlite3 stores metadata, fulltext and float32 vectors.
  Existing schema 1 migrates transactionally to schema 2 on update/rebuild.
  Older binaries that only support schema 1 cannot open the upgraded index.
  Model preflight happens before writes; fatal failures roll back both index updates.
  Disabled semantic search retains old vectors and reports stale content as a warning.

  Embeddings are numerical representations, not LLM text generation.
  Only title/abstract are embedded; PDF text, authors and journals are excluded.
  Similarity is not a probability. Verify scientific claims against originals.
  Long abstracts are split by actual token counts; each paper appears once.
  Missing abstracts are flagged title_only; empty entries are skipped/counted.
  Model/signature changes require --index update. All normal retrieval is offline.
  Setup/model acquisition never uploads bibliography text.
  設定・モデル取得・統合索引・MCPの詳細: docs/semantic-search.md
